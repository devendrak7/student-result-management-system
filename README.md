# 🎓 Student Result Management System

A console-based **Student Result Management System** developed using **Python**. This project helps manage student academic records using JSON file handling and a menu-driven interface.

## ✨ Features

- ➕ Add Student Records
- 📋 View All Students
- 🔍 Search Student by Roll Number
- ✏️ Update Student Details
- ❌ Delete Student Records
- 📊 Automatic Percentage Calculation
- 🏅 Automatic Grade Calculation
- 💾 JSON File Storage
- 🖥️ Menu-Driven Interface

---

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Command Line Interface (CLI)

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/devendrak7/student-result-management-system.git
```

2. Open the project folder

```bash
cd student-result-management-system
```

3. Run the project

```bash
python Student_Result_Management_System.py
```
